Training the TwoTowerDNN with an inbatch softmax loss
and using the metric composite_ndcg@20 on the validation set for early stopping,
minimum threshold, and model selection by the keras tuner BayesianOptimization.

The model learning looks healthy.
  - The train vs validation curves for loss and metrics can be seen
    in the sub-directory best_fitting_model_stats.  
The best fitting hyperparameters are also in that subdirectory.
The model is saved to src/test/resources/serving_model

Best fitting model used a batch size of 2056:
   composite ndcg@20 = 0.204
   head ndcg@20 = 0.467
   torso ndcg@20 = 0.152
   tail ndcg@20 = 0.017
   ndcg@20 = 0.023
   mrr@20 = 0.027
   recall@20 = 0.035
   hit rate = 0.026


The ndcg@20 is 4.6 times random performance and the
    individual components for ndcg hard, torso, and tail are
    93, 30, and 3 times random perfomance respectively.
The mrr@20 is ~ 8 times random performance.
The recall@20 ~ 3 times random performance.
